## 一、安装 / 卸载

| # | 项目 | 操作 | 预期 |
|---|------|------|------|
| 1 | 安装向导 | 双击 Setup → 选 D 盘 | 落位 `D:\EarthOnline`（单层），无 `D:\EarthOnline\EarthOnline` |
| 2 | 旧双层折叠 | 把旧 `D:\EarthOnline\EarthOnline` 路径粘进安装目录 | 自动收敛为 `D:\EarthOnline` |
| 3 | 桌面/开始菜单快捷方式 | 勾选安装 | 双击快捷方式可启动，图标为琥珀地球新图标 |
| 4 | 「应用和功能」 | 设置 → 应用 → 地球Online → 卸载 | 出现条目；卸载后目录/快捷方式/注册表键清空 |
| 5 | 静默安装 | `EarthOnline-Setup.exe /silent /dir=D:\X /desktop` | 无 UI 完成安装 |
